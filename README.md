# 岸标 ANBIAO

一个只做三件事的个人 web 工具：**设计、存储、指路**。当前版本：**2.0.0**。

- 主页以**合集标题卡片**呈现，点击合集进入合集页，只显示该合集中的内容。
- 指路支持按**站点、主人、网页标签、全局**四种范围搜索。
- 网页可添加多个标签；标签会显示在卡片和主页顶部。
- 图片、视频、音频、文件都支持多文件/选集详情页；图片支持多张图集，图集中每一张都可以点开看大图。
- 视频、音频、文件的选集使用真实上传文件，不支持只有文字或只有链接的选集项。
- 自定义底色/背景图使用高对比度文字卡片，背景再复杂也不会让正文融进去。
- 手机浏览器已适配：主页、合集、详情页、图集和评论都会按单列/全宽显示。
- 文章改为独立写作页：点击“添加内容 → 文章”会直接进入写作页，支持字号、加粗、斜体、下划线、删除线、首行缩进、行距、插图、智能排版，并可在写作页选择文章所属合集；「直接读取文档」会按文档的 Heading 1/2 或 Markdown 标题划分章节，把标题填入章节名称、把正文填入对应章节。
- 图片、视频、音频、文件的主文件改为可选；可以只建立合集，也可以只放单个文件。视频合集支持在合集里继续添加子合集；图片合集以多图平铺缩略图展示；音频/文件合集带侧边栏，点击名称切换查看对应内容；文章的章节继续使用章节侧边栏。
- 工作台最下方提供「自定义页面布局」和「AI 辅助布局」：进入独立布局画布，可拖动主视觉/搜索/内容区到 12 列网格的不同位置，调整宽高、主视觉样式、合集顺序和分栏；AI 会按内容类型和数量给出一版可继续修改的方案。
- 一个账号最多管理 5 个网页；设置页和账号页都有「管理我的网页」，可查看每个网页的标题、路径、内容数量、公示状态，并可直接「查看网页」或进入编辑。
- 管理页支持撤销公示、删除网页和清理“云端旧记录”；删除/撤销都需要二次确认。已登录时指路以云端已发布记录为准，不再混入本地草稿快照。
- 阅读页、文章正文和详情页会根据背景自动使用深/浅文字配色，并在自定义背景上增加高对比阅读底板。
- 发布时会先把图片上传到 Supabase Storage，再把本地图片地址替换为公开 URL，减少本地状态和发布请求的体积。
- 主人可一次性设置单个/整个专区的视频、音频、图片是否允许下载。
- 支持用户注册、邮箱确认、登录；评论绑定账号，主人可以查看访客记录。
- 后端已迁移到 **Supabase**，不再需要运行 Python `server.py`。

## 后端：Supabase

项目配置：

- Supabase URL：`https://qdphpjcxluayglvzvafp.supabase.co`
- Bucket：`images`
- 邮箱确认：已按“需要确认”设计

初始化步骤见 [SUPABASE.md](<SUPABASE.md>)，核心是：

1. 在 Supabase SQL Editor 执行 [supabase-setup.sql](<supabase-setup.sql>)。
2. 在 Authentication → Providers → Email 开启 Email 和 Confirm email。
3. 在 Authentication → URL Configuration 填写静态站点地址和 Redirect URLs。
4. 把整个项目部署到 Cloudflare Pages / Netlify / Vercel / GitHub Pages 等静态托管。
5. 所有用户访问同一个静态站点地址。

Supabase 不是静态网站托管服务；`index.html` 和 `assets/` 仍然需要一个静态站点地址。

## 两种使用方式

### 在线模式：静态站点 + Supabase

部署到静态托管后：

- 不同局域网的用户通过同一个网址访问。
- 注册/登录、评论、网页、访客记录和媒体都写入 Supabase。
- 发布后，其他人刷新「指路」即可看到；前端也订阅了 Supabase Realtime，会尝试自动刷新。
- 公开的只是主人确认过的快照，不是实时草稿。

### 本地模式：双击 `start.bat` / `index.html`

不需要后端，适合本地写作和预览。站点结构、评论、下载设置保存在浏览器 `localStorage`，文件在 IndexedDB。

本地模式下 Supabase Auth 仍可能加载，但邮箱确认链接需要一个 http(s) 静态站点地址；正式登录请使用在线模式。

## 主要功能

### 网页标签与搜索

- 「站点设定」里的网页标签用逗号分隔，最多 8 个。
- 标签显示在指路卡片和主页顶部。
- 指路搜索范围：
  - **站点**：只匹配站点名称
  - **主人**：只匹配主人署名
  - **标签**：只匹配网页标签
  - **全局**：匹配站点、主人、标签、简介和内容标题

### 合集式主页

- 主页不直接铺开单篇文章/视频，而是显示合集标题卡片。
- 点击合集进入合集页，只展示该合集及子合集中的内容。
- 合集页有合集选择器，可切换到其他合集。
- 合集卡片、图片高度和间距都做了紧凑化。

### 内容类型

- **文章**：摘要、正文、配图、可选章节（每章最多 4 万汉字）
- **图片**：主图 + 多张图集，可设置下载
- **视频**：外部链接或本地视频，可添加选集
- **音频**：外部链接或本地音频，可添加选集
- **文件**：多个实际文件，可添加文件分区
- **链接**：去向地址与说明
- **短句**：独立引文与出处

### 详情页与评论

- 文章有独立阅读页和章节选择。
- 视频、音频、文件、图片有独立详情页：
  - 发布者备注
  - 媒体播放/文件打开
  - 选集/分区
  - 评论块区
- 评论为文字与符号，支持回复，没有点赞。
- 在线评论需要登录，评论会绑定到 Supabase Auth 账号。
- 文章正文与阅读页禁止选中复制（界面级限制）。

### 下载设置

- 「我的 Web → 05 下载设置」按单个视频/音频/图片切换。
- 支持本专区全部允许/禁止、全部允许/禁止。
- 视频/音频/图片详情页会直接显示下载入口；未开放时显示提示。
- 下载设置写入下一次公示快照。

### 账号与访客

- **每个账号的本地草稿是隔离的**：登录 A 和登录 B 会加载各自的主页，不会互相覆盖。
- 在新设备或清空本地数据后登录，会尝试从 Supabase 拉取该账号最近发布的站点，避免重复创建。
- 同一浏览器同一时间只保持一个 Supabase 登录会话；要同时登录两个账号，请使用两个浏览器配置文件/无痕窗口。
- 如果两个账号使用相同的站点路径，发布时会自动追加后缀避免冲突。
- `/login` 页面：邮箱 + 密码登录；注册需要邮箱确认。
- `profiles` 保存用户名、显示名。
- `sites.owner_id` 绑定发布者账号。
- `comments.user_id` 绑定评论者账号。
- 「我的 Web → 06 访客记录」展示访客显示名/匿名标识、页面、时间和设备信息。
- 访客记录只有站点主人可读；撤回公示时删除该站点的评论和访客记录。

## 数据与备份

- **Supabase**：`profiles`、`sites`、`comments`、`visits`、Storage `images`。
- **本地模式**：`localStorage`（站点、评论、下载设置）+ `IndexedDB`（上传文件）。
- **JSON 备份**：浏览器端仍可导出本地草稿和本地文件。

Supabase 数据库请使用 Dashboard 的备份/PITR 能力；Storage 也需单独备份。

## 旧数据说明

- 本地浏览器中的草稿、图片、评论和下载设置仍在本地；登录后重新公示会创建 Supabase 站点记录。
- 旧 `server.py` 的账号密码是 PBKDF2 哈希且没有邮箱字段，不能直接导入 Supabase Auth。旧账号需要重新注册（或由管理员创建），旧评论/访客记录如仍保留在 `server_data/`，需要按 Supabase 表结构单独导入。
- 当前仓库没有随附 `server_data/`，因此已经删除的服务器数据无法从这里恢复。

## 已知限制

- Supabase 免费计划的 Storage、数据库和邮件发送都有配额。
- 图片以本地数据保存，数量/体积受浏览器配额限制；视频、音频、文件上传到 Supabase Storage，受 Supabase 配额限制。
- 登录需要邮箱确认；本地 `file://` 地址不能作为邮箱确认回跳地址，正式使用请部署静态站点。
- 当前没有 password reset、账号资料编辑、评论审核、限流等生产功能。
- 下载控制是界面/链接级限制，无法阻止录屏或技术抓取。
- 媒体 Storage bucket 当前为 public read；需要更严格控制时改为私有 bucket + signed URL。
